# Edit-Check Pass

High-level structural and rhetorical checks. Adapted from paper-revision-editor (ipeirotis).

## Check 1: Puzzle-first opening
First paragraph poses a question the reader did not know to ask.

## Check 2: One named idea per paper
Central claim should fit a memorable phrase.

## Check 3: Question before machinery
Formal definitions appear only after reader knows why to care.

## Check 4: Working examples
Each example should do work, not just illustrate. Cut if removable without loss.

## Check 5: Figures as primary text
Captions should convey the contribution to a skim-reader.

## Check 6: Progressive disclosure
Simple version first, complications after. Defer non-load-bearing caveats.

## Check 7: Named items in remembered lists
Replace "First/Second/Third" with named items for memorable lists.

## Check 8: Cut promotional adjectives
"Important", "novel", "interesting", "crucial" — delete and verify substance survives.

## Check 9: Standalone intro and conclusion
Reader who reads only these should summarize the contribution.

## Meta: Layered audience passes
1. Curious non-expert — would they read past paragraph two?
2. Generalist reviewer — would they think the question matters?
3. Technical expert — would they find the core defensible?

## Meta: Default to a 20% cut
Most drafts carry 15-25% that does not serve the story. Cut by keep-test, not toward a target.
