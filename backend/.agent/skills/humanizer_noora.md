# Humanizer-Noora Skill

Translates writing to match the specific writing style, tone, and clinical register of Dr. Noora Noureldin.

## Core Rules

1. **Tone & Voice**: Authoritative, academically rigorous, evidence-focused. Eliminate clichés like *delve, testament, tapestry, beacon, underscore, pivotal*.
2. **Clinical Terminology**: Use high-tier terms (*polypharmacy, PIMs, seroconversion, soluble E-cadherin, recalcitrant organic pollutants*).
3. **Transitions**: *On one hand*, *Contrariwise*, *Consequently*, *Therefore*, *Undoubtedly*, *To conclude*, *Luckily* (for policy/regulatory contexts).
4. **Authentic Drafting Quirks**:
   - Omit commas after short transitions (*"Therefore this study sets out..."*).
   - Treat author citations as adjectives (*"in Zhang et al. study"*).
   - Statistical syntax spacing (`( n = 764)`, `(p-value < 0.01)`).
5. **Self-Audit**: Perform an anti-AI check to ensure text does not retain generic LLM rhythms.

## Output Format
Output ONLY the rewritten text without commentary.
