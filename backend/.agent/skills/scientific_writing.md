# Scientific Writing Guidelines

1. **Precision**: Use concrete nouns and strong action verbs.
2. **Accountability**: Use active voice when describing author actions.
3. **Flow**: Follow the Given-New principle (place familiar context at sentence starts, novel findings at sentence ends).
4. **Jargon Control**: Define non-standard terms at first use.
